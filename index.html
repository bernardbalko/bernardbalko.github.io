02 Projects
001
Smart Posture Trainer
A wearable mechatronic system that monitors posture in real time using an MPU6050 IMU and flex sensor mounted on a chest strap. The STM32H503RB microcontroller fuses dual sensor data through a low-pass filter and calibration-based baseline system, triggering haptic (vibration motor) and visual (red LED) feedback only when poor posture is sustained for over one second — eliminating false positives from natural movement.

002
UR10e 6-DOF Robot Kinematics — MuJoCo Simulation
Implemented forward and inverse kinematics (position & velocity) from scratch for the Universal Robots UR10e manipulator inside a MuJoCo physics simulation. Derived transformation matrices from DH parameters, solved nonlinear IK using scipy, computed the Jacobian for velocity mapping, and implemented a PD torque controller for stable joint-angle tracking.

003
Aerial Vehicle Rapid 3D Map Generation for Safe Landing Area Detection
Designed and built a compact multi-sensor LiDAR scanning turret mounted on a 3DOF pan-tilt mechanism to help aerial vehicles identify safe autonomous landing zones. A 9DOF IMU provided angular feedback for servo control accuracy, while ICP stitched multiple point clouds into a full 3D terrain map. MSAC plane segmentation classified flat, wall, and non-flat surfaces. Variable voxelization (1×1, 5×5, 10×10) was benchmarked for optimal speed/accuracy trade-off. Published at ASME IMECE 2022, University of Hartford Autonomous Mobile Robotics Lab.
